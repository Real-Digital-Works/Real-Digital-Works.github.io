# Real Digital Works

Company site for Real Digital Works — a Real Animation Works company.

Live: GitHub Pages on the `Real-Digital-Works` organisation.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Pushes to `main` build a static export and publish to GitHub Pages.

The contact form opens a mail message to the studio. There is no server on Pages.
